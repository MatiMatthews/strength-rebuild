# Fields and choices

Editable controls use explicit Athlete surfaces and readable foregrounds. Field boundaries use the muted text color; validation borders use the theme's danger foreground. Placeholders and disabled values remain readable. Choice markers use ink on signal when selected, and the current theme foreground on an explicit surface otherwise. Press feedback thickens the boundary without fading text or markers.

Settings and preparation choices expose pending saves as busy and disabled. Weekly outcome and replacement-reason choices share the same primitive. Theme changes preserve component identity, focus and intermediate decimal drafts. Invalid input and cancellation do not write; a failed save retains the draft for retry.

Regression coverage measures rendered native component styles and browser-computed text, placeholder, marker and boundary contrast in both themes. Real route journeys independently read SQLite after validation, cancel, failed/duplicate saves, retry and reopen, including immutable workout/history checks.
